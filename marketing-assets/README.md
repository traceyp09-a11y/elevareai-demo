# ElevareAI Marketing Logo Assets

This folder contains the ElevareAI logo files for marketing and branding purposes.

## Logo Files

### Full Logos (Icon + Text)

**`elevareai-logo-dark.svg`**
- Use on: Light backgrounds (white, light gray, etc.)
- Text color: Dark gray (#1f2937)
- Best for: Presentations, websites with light themes, print materials

**`elevareai-logo-light.svg`**
- Use on: Dark backgrounds (black, dark gray, navy, etc.)
- Text color: White (#ffffff)
- Best for: Dark-themed websites, dark slide backgrounds, video overlays

### Icon Only

**`elevareai-icon.svg`**
- Icon without text
- Size: 48x48px (scalable)
- Best for: App icons, favicons, social media profile pictures, small spaces

## Design Elements

### Colors
- **Primary Gradient**: Cyan (#06b6d4) to Blue (#3b82f6)
- **Accent**: Cyan (#06b6d4)
- Uses: All gradient effects on the E, arrow, and ring

### Components
1. **Stylized "E"** - Represents "Elevare" (to elevate, to rise)
2. **Upward Arrow** - Symbolizes growth, improvement, and upward trends
3. **Circular Ring** - Represents continuity, holistic approach, and 360° insights
4. **Accent Dots** - Modern tech aesthetic, suggests data points and AI

## Usage Guidelines

### Platform vs Marketing
- **ElevareIQ** = Internal analytics platform (HR, HSE, Operations, QC dashboards)
- **ElevareAI** = Marketing brand name for external materials

### Recommended Sizes
- **Website header**: 200x60px
- **Social media cover**: Scale proportionally
- **Business cards**: 150x45px
- **App icon**: Use `elevareai-icon.svg` at 512x512px minimum
- **Favicon**: Use `elevareai-icon.svg` at 32x32px or 64x64px

### File Formats
All files are SVG (Scalable Vector Graphics):
- ✅ Scales to any size without quality loss
- ✅ Small file size
- ✅ Works on web, print, and digital media
- ✅ Can be converted to PNG, JPG, or PDF as needed

## Converting SVG to Other Formats

### To PNG (for social media, email):
```bash
# Requires ImageMagick or similar tool
convert elevareai-logo-dark.svg -resize 1200x elevareai-logo-dark.png
```

### To PDF (for print):
- Open SVG in Adobe Illustrator or Inkscape
- Export as PDF with high-quality settings
